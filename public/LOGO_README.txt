The app uses the logo at: /sreedhar-logo.svg (file: sreedhar-logo.svg in this folder).

This SVG shows "Sreedhar CCE" and always displays correctly. The previous sreedhar-logo.png
in this folder was invalid (the server returned HTML, not an image).

To use your own logo from the website:
1. Download the image from https://sreedharscce.com (e.g. right-click the logo → Save image as).
2. Save it as sreedhar-logo.png in this folder.
3. In the codebase, change all references from /sreedhar-logo.svg to /sreedhar-logo.png.
